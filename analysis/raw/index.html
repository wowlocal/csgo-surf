Movement rules

        
        
        
Leaderboard runs use auto bunnyhop with capped starting speed. You can jump in the start zone, but excess horizontal speed is reduced when you leave: 325 units/s grounded, 350 airborne. Unrestricted starts keep separate local bests and never enter the leaderboard. Changing a rule restarts your run.

        

        
Practice

        
        

        
Save a tricky approach and try it again. Restoring a position keeps the run in practice mode.
